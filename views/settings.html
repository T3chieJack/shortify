What gets recorded

For each visit: the time, the link, the referring site's name, the browser, device, operating system and language. The country too, if Cloudflare or your proxy provides it. IP addresses are not stored. Visitors are counted with a code that changes daily, so nobody can be followed from one day to the next.

If people outside your household use your links, check whether privacy rules where you live ask you to tell them.
